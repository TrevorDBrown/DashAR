# General Templates

This directory contains general templates, skeleton frameworks, and other relevant resources for the DashAR system.

## PythonTemplate.py

This is a template file used when creating a new Python script for the DashAR System. These are generally reserved for source code for the Data Aggregator and Server application.

## ShellTemplate.sh

This is a template file used when creating a new shell script (i.e. zsh, bash, etc.) for the DashAR System. These are generally reserved for build scripts, development tools, etc.
