# Heads Up Display (HUD) Templates

This directory contains templates and skeleton frameworks for data and configurations used in the Heads Up Display (HUD) of the DashAR system.

## base.json

This collection of JSON files define the HUD base elements layout (trays and anchors), as well as the specified widget configuration to use (default.json, or whatever is set as the custom configuration).

## default.json

This collection of JSON files define the default widget configuration used by DashAR. This is used as a fallback if either no custom HUD is defined, or if the custom HUDs are unavailable.
